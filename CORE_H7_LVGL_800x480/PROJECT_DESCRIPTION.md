# CORE_H7_LVGL_800x480 — Описание проекта

## Общее описание

Проект для микроконтроллера **STM32H743II** (ядро ARM Cortex-M7).
Реализует графический интерфейс на дисплее **1024x600** с ёмкостным сенсорным экраном.
Среда разработки: **STM32CubeIDE 2.1.1**, конфигурация периферии через **STM32CubeMX**.

---

## Аппаратная конфигурация

| Параметр | Значение |
|---|---|
| MCU | STM32H743IIT (Cortex-M7, 480 МГц макс.) |
| Дисплей | 1024x600 пикселей, RGB565 (16 бит на пиксель) |
| Тачскрин | GT911 — ёмкостный, до 5 касаний одновременно |
| Внешняя SDRAM | 8 МБ по адресу 0xC0000000 (используется под фреймбуфер) |
| Flash | 2 МБ (код программы) |
| Внутренняя RAM | ~1 МБ (разбита на несколько регионов) |

### Распиновка ключевых GPIO

| Пин | Назначение |
|---|---|
| PE2 | LCD_RST — сброс дисплея |
| PE3 | GT911_INT — прерывание от тачскрина |
| PE4 | INTERUPT — внешнее прерывание (общее) |
| PC13 | LED_DO — управление светодиодом |
| PH6 | BL_PWM — ШИМ подсветки дисплея |
| PH7 | GT911_RST — сброс тачскрина |
| PD12, PD13 | I2C4_SCL, I2C4_SDA — шина I2C для тачскрина |

## Описание пользовательских файлов

### Core/Src/main.c — Главный файл приложения (~655 строк)

Это **точка входа** и основная логика приложения.

**Что делает функция `main()`:**
1. Включает кэш инструкций (I-Cache) и кэш данных (D-Cache) для ускорения
2. Инициализирует HAL (библиотеку абстракции оборудования)
3. Настраивает системные тактовые частоты (`SystemClock_Config`)
4. Инициализирует всю периферию: GPIO, FMC, I2C4, LTDC, DMA2D
5. Инициализирует внешнюю SDRAM (`SDRAM_InitSequence`)
6. Инициализирует дисплей через LTDC
7. Инициализирует тачскрин GT911
8. Запускает библиотеку LVGL — регистрирует драйвер дисплея и ввода
9. Создаёт демо-интерфейс `lv_demo_widgets()`
10. Входит в бесконечный цикл, где вызывает `lv_timer_handler()` — обработчик LVGL

**Ключевые функции в main.c:**

| Функция | Что делает |
|---|---|
| `main()` | Точка входа: инициализация всего и запуск LVGL |
| `my_disp_flush()` | Callback для LVGL — отправляет нарисованную область на экран через DMA2D |
| `my_touchpad_read()` | Callback для LVGL — читает координаты касания с GT911 |
| `EXTI3_IRQHandler()` | Обработчик прерывания от тачскрина (ставит флаг касания) |
| `tabview()` | Создаёт пользовательский UI с 8 вкладками |
| `Color_To_565()` | Конвертирует RGB888 в формат RGB565 |
| `SystemClock_Config()` | Настройка PLL и тактирования (сгенерирован CubeMX) |

**Вкладки интерфейса (функция `tabview`):**
1. Description — описание
2. Analytics — аналитика (виджеты meter и chart)
3. Battery — батарея
4. LED — управление светодиодами
5. RS232 — интерфейс RS232
6. RS485 — интерфейс RS485
7. Output — выходы
8. Input — входы

### Core/Src/ltdc.c — Драйвер дисплея (~393 строк)

Управляет контроллером **LTDC** (LCD-TFT Display Controller) — встроенным аппаратным блоком STM32 для вывода изображения на дисплей.

| Функция | Что делает |
|---|---|
| `MX_LTDC_Init()` | Инициализация LTDC: тайминги дисплея, формат пикселей RGB565, адрес фреймбуфера в SDRAM (0xC0000000) |
| `LTDC_Fill()` | Заполняет прямоугольную область одним цветом (использует DMA2D) |
| `LTDC_Color_Fill()` | Копирует буфер пикселей в фреймбуфер (используется LVGL для вывода) |
| `LTDC_Clear()` | Очищает весь экран заданным цветом |

**Как работает связка LVGL → LTDC:**
LVGL рисует интерфейс во внутренний буфер → вызывает `my_disp_flush()` → та вызывает `LTDC_Color_Fill()` → DMA2D аппаратно копирует данные в фреймбуфер SDRAM → LTDC автоматически считывает фреймбуфер и отправляет на дисплей.

---

### Core/Src/dma2d.c — Инициализация DMA2D (~107 строк)

**DMA2D** — это аппаратный ускоритель 2D-графики в STM32H7. Умеет быстро:
- Заливать области одним цветом
- Копировать блоки пикселей из памяти в память
- Конвертировать форматы пикселей

| Функция | Что делает |
|---|---|
| `MX_DMA2D_Init()` | Настраивает DMA2D в режим Memory-to-Memory, формат RGB565 |

Используется в `ltdc.c` для аппаратного копирования пикселей (вместо медленного `memcpy`).

---

### Core/Src/fmc.c — Контроллер внешней памяти (~353 строк)

**FMC** (Flexible Memory Controller) — управляет подключённой внешней SDRAM.

| Функция | Что делает |
|---|---|
| `MX_FMC_Init()` | Настраивает FMC для работы с SDRAM: тайминги, ширина шины, CAS Latency |

Поддерживает микросхемы SDRAM типа **W9864G6** (64 Мбит = 8 МБ). SDRAM используется как фреймбуфер дисплея — в неё записывается изображение, а LTDC из неё читает.

---

### Core/Src/bsp_sdram.c — Последовательность инициализации SDRAM (~83 строки)

SDRAM требует определённой последовательности команд для начала работы.

| Функция | Что делает |
|---|---|
| `SDRAM_InitSequence()` | Выполняет 8 шагов инициализации SDRAM: подача тактирования, precharge, auto-refresh, установка Mode Register |

Вызывается один раз в `main()` после `MX_FMC_Init()`.

---

### Core/Src/gpio.c — Настройка портов ввода/вывода (~112 строк)

| Функция | Что делает |
|---|---|
| `MX_GPIO_Init()` | Настраивает все GPIO-пины: LCD_RST, GT911_INT/RST, LED, подсветку, прерывание |

Конфигурирует пин PE3 (GT911_INT) на прерывание по спадающему фронту — это позволяет тачскрину "будить" микроконтроллер при касании.

---

### Core/Src/i2c.c — Настройка шины I2C (~141 строка)

| Функция | Что делает |
|---|---|
| `MX_I2C4_Init()` | Настраивает I2C4 на частоту 100 кГц (стандартный режим) |

I2C4 используется **только** для связи с тачскрин-контроллером GT911.

---

### Core/Src/stm32h7xx_it.c — Обработчики прерываний (~219 строк)

| Обработчик | Что делает |
|---|---|
| `SysTick_Handler()` | Вызывается каждую 1 мс — инкрементирует счётчик HAL и счётчик тиков LVGL |
| `DMA2D_IRQHandler()` | Срабатывает при завершении DMA2D-операции (копирования пикселей) |
| `HardFault_Handler()` и др. | Обработчики ошибок ядра (бесконечный цикл при сбое) |

---

### Core/Src/stm32h7xx_hal_msp.c — MSP-инициализация

**MSP** (MCU Support Package) — низкоуровневая инициализация периферии: включение тактирования, настройка пинов для конкретного модуля. Вызывается автоматически из HAL при инициализации каждого периферийного блока.

Сгенерирован CubeMX, редактировать не нужно.

---

### Core/Src/memorymap.c — Карта памяти (~30 строк)

Шаблонный файл, практически пустой. Зарезервирован для пользовательского маппинга памяти.

---

### Core/Src/syscalls.c и sysmem.c — Системные вызовы

Стандартные заглушки для работы с newlib (стандартная библиотека C). Обеспечивают функции `_write`, `_read`, `_sbrk` и т.д. **Редактировать не нужно.**

---

### Core/Src/system_stm32h7xx.c — Инициализация системы

Начальная настройка микроконтроллера: FPU, вектор прерываний. Вызывается автоматически до `main()`. **Сгенерирован, редактировать не нужно.**

---

### Core/Startup/startup_stm32h743iitx.s — Стартовый код (ассемблер)

Самый первый код, выполняемый при включении. Настраивает стек, обнуляет BSS-секцию, копирует данные из Flash в RAM, вызывает `SystemInit()` и потом `main()`. **Редактировать не нужно.**

## Пользовательские модули (MODULES/)

### MODULES/GT911/ — Драйвер тачскрина

Драйвер ёмкостного тачскрин-контроллера **Goodix GT911**.

**Файлы:** `GT911.h`, `GT911.c`

| Функция | Что делает |
|---|---|
| `GT911_Init()` | Инициализация контроллера: сброс, запись конфигурации, установка разрешения |
| `GT911_ReadStatus()` | Чтение статуса: есть ли касание |
| `GT911_ReadXY()` | Чтение координат касания (X, Y) |
| `GT911_WriteConfig()` | Запись конфигурационных регистров с контрольной суммой |

**Где используется:** В `main.c` → `my_touchpad_read()` — LVGL вызывает эту функцию каждые 15 мс для проверки касания.

**Связь с оборудованием:**
- I2C4 (PD12/PD13) — обмен данными
- PE3 — прерывание (касание)
- PH7 — аппаратный сброс контроллера

---

### MODULES/IMAGE/ — Работа с BMP-изображениями

**Файл:** `BMP.h`

Содержит только определение структуры заголовка BMP-файла. Вспомогательный модуль для возможного отображения BMP-картинок на экране. В текущем коде **активно не используется**.

## Подключённые библиотеки

### 1. LVGL (Light and Versatile Graphics Library)

**Расположение:** `Drivers/lvgl/`
**Версия:** 8.4.0
**Конфигурация:** `Drivers/lvgl/lvgl/lv_conf.h`

**Что это:** Популярная open-source библиотека для создания графических интерфейсов на встраиваемых системах (кнопки, слайдеры, графики, анимации и т.д.).

**Ключевые настройки:**
- Глубина цвета: 16 бит (RGB565)
- Внутренний буфер памяти: 48 КБ
- Период обновления дисплея: 16 мс (~60 FPS)
- Период опроса ввода: 15 мс
- DPI: 130 пикселей/дюйм

**Как подключена к проекту:**
- `main.c` вызывает `lv_init()` для инициализации
- Регистрирует callback `my_disp_flush()` — LVGL через него отправляет пиксели на экран
- Регистрирует callback `my_touchpad_read()` — LVGL через него получает координаты касания
- В бесконечном цикле вызывается `lv_timer_handler()` — основной цикл LVGL
- Используется демо `lv_demo_widgets()` для отображения виджетов

**Структура каталогов LVGL:**
- `src/core/` — ядро: объекты, события, стили
- `src/draw/` — движок отрисовки
- `src/widgets/` — виджеты (кнопки, слайдеры, метки и т.д.)
- `src/extra/` — расширенные виджеты и функции
- `src/hal/` — HAL-интерфейс LVGL (не путать с STM32 HAL)
- `src/font/` — шрифты
- `demos/` — демо-приложения

---

### 2. STM32 HAL (Hardware Abstraction Layer)

**Расположение:** `Drivers/STM32H7xx_HAL_Driver/`
**Поставщик:** STMicroelectronics

**Что это:** Официальная библиотека от ST для работы с периферией микроконтроллера. Предоставляет функции вида `HAL_XXX_Init()`, `HAL_XXX_Start()` и т.д.

**Какие модули HAL используются в проекте:**

| Модуль | Для чего |
|---|---|
| HAL_GPIO | Управление пинами ввода/вывода |
| HAL_RCC | Настройка тактирования (PLL, частоты шин) |
| HAL_LTDC | Управление LCD-контроллером |
| HAL_DMA2D | Управление 2D-ускорителем графики |
| HAL_FMC / SDRAM | Управление внешней SDRAM |
| HAL_I2C | Обмен данными по I2C (тачскрин) |
| HAL_DMA | Прямой доступ к памяти |
| HAL_EXTI | Внешние прерывания (касание) |
| HAL_PWR | Управление питанием |
| HAL_CORTEX | Настройка ядра (MPU, кэш) |
| HAL_FLASH | Работа с Flash-памятью |

---

### 3. CMSIS (Cortex Microcontroller Software Interface Standard)

**Расположение:** `Drivers/CMSIS/`
**Поставщик:** ARM / STMicroelectronics

**Что это:** Стандартный набор заголовочных файлов, определяющих регистры микроконтроллера, адреса периферии, и базовые функции ядра Cortex-M7. HAL работает поверх CMSIS.

**Используется неявно** — через HAL и стартовый код.

## Что можно редактировать, а что нет

### Можно и нужно редактировать:
- `Core/Src/main.c` — основная логика (между комментариями `/* USER CODE BEGIN */` и `/* USER CODE END */`)
- `MODULES/GT911/*` — драйвер тачскрина
- `MODULES/IMAGE/*` — работа с изображениями
- `Drivers/lvgl/lvgl/lv_conf.h` — настройки LVGL

### Нельзя редактировать вручную (перезатрутся CubeMX):
- Код **вне** блоков `USER CODE` в файлах `Core/Src/` и `Core/Inc/`
- `stm32h7xx_hal_conf.h` (редактируется через CubeMX)
- `system_stm32h7xx.c`
- Файлы HAL-драйверов в `Drivers/STM32H7xx_HAL_Driver/`

### Не нужно трогать:
- `Core/Startup/` — стартовый код
- `Drivers/CMSIS/` — заголовки CMSIS
- `syscalls.c`, `sysmem.c` — системные заглушки
